# PRO Helper - Quick Start Guide

Get up and running with PRO Helper in 5 minutes!

## 1. Install (1 minute)

- Download: `PROHelper Setup 1.0.0.exe`
- Run the installer
- Select installation folder
- Done!

## 2. First Launch (1 minute)

1. Open PRO Helper from Start Menu
2. The app will open with the Pokedex
3. Backend starts automatically

## 3. Configure OCR Zone (2 minutes)

1. Go to **Settings** tab
2. Click **Set OCR Zone**
3. Draw a box around the **opponent's Pokemon name** in your game
4. Click **Confirm**

Example: If the opponent's name appears in the top-right corner, select that area.

## 4. Add Your Team (1 minute)

1. Go to **Team** tab
2. Search for your Pokemon (e.g., "Pikachu")
3. Click the suggestion to add
4. Repeat until you have 6 Pokemon

**Alternative**: Click **Detect Team via OCR** to auto-detect your team.

## 5. Start Playing!

1. Open Pokemon Revolution Online
2. Press **F9** to toggle the overlay on/off
3. When you encounter a Pokemon:
   - The overlay shows enemy stats
   - See weaknesses & resistances
   - Get recommended Pokemon to switch to

## 🆘 Most Common Issues

### "My Pokemon isn't being detected"
→ Adjust the OCR zone to cover more area
→ Try Settings → Reset Zone

### "Overlay isn't showing"
→ Press F9
→ Check Settings → Auto Battle Mode is enabled
→ Make sure the game window is visible

### "Search shows no results"
→ Use correct English name: "Pikachu" (not "Pika")
→ Try searching by ID number instead: "25"

## 📊 Understanding Type Effectiveness

When you search a Pokemon, you'll see a **Type Effectiveness** chart:

- **Green (×2)** = Super effective! (good damage)
- **Yellow (×1)** = Normal damage
- **Blue (×½)** = Not very effective
- **Red (×0)** = No effect/Immune

### Example: Pikachu (Electric)
- **Strong against**: Water, Flying
- **Weak against**: Ground
- **Resistant to**: Electric, Flying, Steel

## 💡 Pro Tips

1. **OCR works best** when:
   - Pokemon name has good contrast with background
   - Game is at 1080p or higher resolution
   - No screen overlays from other apps

2. **Team recommendations** work when:
   - Your team is saved
   - You have an "active" Pokemon (click Active button)
   - App has detected at least one opponent

3. **Faster searching**:
   - Use Pokemon ID numbers (e.g., "25" for Pikachu)
   - Or partial names (e.g., "chu" finds Pikachu)

## 🎯 Workflow Example

### Typical Battle Session

1. **Before battle**: Click **Active** on your current Pokemon
